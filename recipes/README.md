# Recipe collections

Chef Bob includes two public collections:

| Collection | Purpose |
| --- | --- |
| [STARTER_RECIPES.md](STARTER_RECIPES.md) | Six illustrative recipes written for Chef Bob, each based on **2 portions**, with explicit quantities and steps for a first plan and portion-scaling examples. They have not been kitchen-tested. |
| [RECIPES.md](../RECIPES.md) | The maintainer's 104 imported recipes and variants, each based on **5 portions**. Includes a scaling guide, source links, and review notes. |

The starter recipes are separate from the imported collection. The local helper reads both collections to recognize recipe IDs. The [example plans](../examples/README.md) use the starter recipes to check quantities and grocery totals.

Recipes added through `/recipe-add` go into private storage outside this repository. To improve a public recipe, follow the [contribution guide](../CONTRIBUTING.md#recipes).
